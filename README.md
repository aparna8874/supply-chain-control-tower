# Supply Chain Control Tower

## Business Question
Can operational data identify shipment delays, market performance differences, and supply-chain risk?

## Stack
Python · Pandas · DuckDB SQL · Tableau

## What I did
- Created a reproducible late-shipment KPI
- Built operational summary metrics
- Compared market-level shipment performance
- Prepared an analytical dataset for Tableau
- Wrote SQL for repeatable KPI analysis
- Built an executive-style Tableau Control Tower

## Results
See [`Report/RESULTS_REPORT.md`](Report/RESULTS_REPORT.md).

- `Python/` — preparation and KPI notebook

- `Visualizations/` — supporting charts
- `Report/` — findings and interpretation
